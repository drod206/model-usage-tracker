Reporting agents

Coverage and interpretation

Totals measure cumulative processing across recorded API calls, not unique text or subscription allowance. Input includes cached context each time it is reported as processed. Repeated conversation history and tool results can dominate input. All recorded usage includes imported historical sessions, not just today.

¹ Cache and reasoning breakdowns are not added again to input/output totals. Imported history is an all-time baseline; time-window views show newly observed increments. Local scheduler records are authoritative; local client observations are retained for coverage, not added twice.

Subscription allowance is separate from token usage. No per-token subscription bill is estimated. Image generation is tracked as jobs rather than invented token counts. This read-only dashboard is available on your private lab network; ingestion requires a dedicated credential over TLS.

No prompts, responses, API keys, screenshots, or provider credentials are collected. Updates every 30 seconds.
